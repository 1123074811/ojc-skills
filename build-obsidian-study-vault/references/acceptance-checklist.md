# Obsidian 学科知识库验收清单

## 1. 资料清单

- [ ] 已盘点所有支持格式，没有遗漏嵌套目录和压缩包解压结果。
- [ ] 已记录物理文件数、SHA-256 唯一内容数和完全重复数。
- [ ] 每个唯一源文件均有转换输出或明确异常说明。
- [ ] 每个源文件均可从资料索引访问，重复文件已标明来源关系。
- [ ] 原始资料未因清理派生文件而丢失。

## 2. 转换完整性

- [ ] PDF 页数、PPT 幻灯片数或文档章节范围与输出可对应。
- [ ] 目录和主要标题逐项对上，没有整章、整节或连续页缺失。
- [ ] 公式密集页、跨页表格、图示和 OCR 低质量页已重点复核。
- [ ] 图片、表格、公式和例题没有因文本化而被静默丢弃。
- [ ] 每份资料至少映射到一个正式笔记或资料索引条目。

## 3. 去噪

- [ ] 公众号、群号、免费分享、扫码、购买、下载站和联系方式无残留。
- [ ] 广告二维码及其 Markdown 引用已移除。
- [ ] 重复页眉、页脚、水印、页码碎片已清理。
- [ ] 派生附件中没有仍被引用的缺失图片。
- [ ] 已抽查删除点前后文，确认没有误删定义、条件、公式或例题。

## 4. Markdown 与知识内容

- [ ] 标题层级、公式定界符、编码和相对路径统一。
- [ ] 没有同名规范节点、旧标题残留或讲义批次名节点。
- [ ] 每个 `type: concept` 笔记都有实质正文和来源。
- [ ] 关键定义、条件、结论、用法和易错点未被过度摘要。
- [ ] 外部补充内容与讲义原文整理清楚区分。

## 5. 图谱

- [ ] 存在实际根节点 Markdown 文件。
- [ ] 根 → 学科 → 可选分册 → 章节 → 知识点可沿 Wikilink 遍历。
- [ ] 父节点链接直接子节点，子节点回链直接父节点。
- [ ] 全局图谱颜色组查询能命中对应层级。
- [ ] 没有为放大节点或强行聚类添加虚假链接。
- [ ] 现有 Canvas 完整保留，新增局部图谱只作为补充。
- [ ] README 已说明原生图谱的力导向布局和节点大小限制。

## 6. 自动检查与交付

- [ ] `audit_vault.py` 的失效链接、缺失附件、噪声和空壳知识点均为 0。
- [ ] 根节点不可达笔记已解释或修复。
- [ ] 仓库既有测试和 `git diff --check` 通过。
- [ ] Git 提交不含模型缓存、临时页图、日志或非必要大文件。
- [ ] 推送后远程目标分支 SHA 与本地 `HEAD` 一致。

## 报告模板

```text
资料：物理文件=<n>，唯一内容=<n>，重复=<n>，未覆盖=<n>
内容：知识点=<n>，空壳=<n>，噪声残留=<n>
链接：Wikilink 失效=<n>，附件缺失=<n>，根节点不可达=<n>
复核：目录/页范围=<状态>，高风险页面=<状态>
Git：<branch> @ <sha>
未解决：<无或逐项列出>
```
